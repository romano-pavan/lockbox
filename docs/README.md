# Screenshots

Terminal captures referenced from the main README. Save them here with these names.

- `init.png`    output of `lockbox init`
- `doctor.png`  output of `lockbox doctor`, showing both refusals
- `restore.png` `lockbox restore` and the row counts that follow
- `denied.png`  an administrator key being refused a delete

Before committing a capture, check it for an exported `AWS_SECRET_ACCESS_KEY`,
a scrolled back `export` line, or anything else in the shell history above the
command. Crop or retake rather than commit and rewrite history later.
